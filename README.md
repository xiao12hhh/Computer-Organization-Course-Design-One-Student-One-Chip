## 提交约定

按学习者要求，每完成一个有意义的小步骤，将相关文件和进度记录提交并推送到本仓库。

1. 开始工作前检查远端更新，保留已有修改。
2. 记录本次改动、实际验证结果、未解决问题和下一步。
3. 检查待提交文件，只提交本次相关内容。
4. 提交说明使用清楚的中文，例如：`docs: 记录开发环境验证结果`。
5. 推送完成后提供提交链接；失败时明确说明，不把本地提交当作已同步。

这是按步骤执行的提交约定，不是后台自动同步。虚拟机、安装包、密钥和编译产物不纳入仓库。
