# 第 9–12 周补学路线

代码已准备好，学习时按下面顺序运行、观察、修改。这里列的是你接下来需要亲自完成的练习，不是已经完成的学习记录。

## 1. 进制和时序电路

打开 `logisim/radix_display.circ`，输入十进制 55，分别观察二进制 00110111、八进制 67、十进制 55、十六进制 37。说明：切换显示方式为什么不改变保存的数值？

阅读 `rtl/week09.sv` 的 shift8、barrel8、lfsr8。手算 0x81 的逻辑右移、算术右移、循环右移；再用实验六核对。能解释寄存器移位需要时钟、桶形移位器不需要时钟，才进入下一步。

## 2. 状态机和键盘协议

给 repeat4 输入 0000011111，逐拍写出 state 和 z；注意重叠检测。阅读 ps2_receiver，找出同步器、下降沿检测、起始位、8 位数据、奇校验和停止位。

按下并松开 A，理解扫描码序列 `1C F0 1C` 与 ASCII `61` 的区别。阅读 key_display，说明为什么重复通码不重复计数，为什么收到 F0 时还不能立刻判定是哪一个键松开。

## 3. CPU 数据通路和八条指令

先看 `tools/minirv_model.py` 的 demo 和 CPU.step，再对照 `tools/generate_minirv.py` 生成的电路。每条指令回答四件事：读哪些寄存器、立即数如何组成、是否访问内存、PC 如何改变。

必须弄清：x0 恒为 0；负立即数需要符号扩展；PC 按字节而 ROM 按字寻址；小端序；sb 只改变一个字节；jalr 的 rd 与 rs1 相同时要读到旧值。亲自把初始数据改为 0x11223344，预测四次 lbu 的结果后运行测试。

## 4. RTL sCPU 和仿真

运行 `make -C npc sim`，打开 `build/scpu-npc/scpu.vcd`。追踪一次 add、一次跳转和最后的 out。对照 `rtl/scpu_io.sv`，说明非阻塞赋值为什么让所有寄存器在同一个边沿更新。

尝试把求和上限改为 5，并相应调整参考程序和测试，结果应为 15。先改自己的分支，保留已经通过的版本。

## 5. C 语言和 NEMU 调试器

补齐指针、字符串、结构体、函数指针、位运算、数组边界和 Makefile。打开 NEMU，依次运行 `info r`、`x 4 $pc`、`si`、`p $pc`，观察客户程序状态变化。

阅读 `pa1/nemu-sdb.c` 和 `pa1/expr.c`，画出表达式从字符到结果的调用过程。手算 `10-3-2`、`1+2*3`、`-1`、`0 && *0`；解释优先级、左结合、无符号回绕和短路求值。

最后独立增加 5 个会失败的输入测试，例如缺括号、除零和未知寄存器，确保报告错误后调试器还能继续使用。
