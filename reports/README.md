# 报告与答辩材料

- [课程设计报告 Word](课程设计报告_整理版.docx)：前八周基础工作、第九至十六周实现、验证、问题分析和待本人补充的心得。
- [答辩讲稿与准备 Word](答辩讲稿与准备_整理版.docx)：约五分钟讲稿、现场演示顺序、十六个追问、补学练习和空白答辩记录。
- [报告文本](course-report.md)与[答辩准备文本](defense-guide.md)：便于版本对照和修改。

技术事实基于提交 e93616d 的代码和已有测试记录，报告整理时未重跑全部历史测试。课程指南的 PDF 第 13 页要求大报告与答辩记录；第 9 页说明第 18 周答辩，具体日期、模板与提交方式仍以教师通知为准。

使用前填写姓名、学号、班级和教师；个人心得要基于亲手阅读、运行和修改补充；实际答辩后再填写教师问题、回答和建议。代码来源、AI 辅助、本地验收范围和 native 试玩的区别已经写入材料。

`build_reports.py` 使用 python-docx 从两份 Markdown 生成 Word。必须在生成后用 Word 或兼容排版引擎导出页面、逐页检查，再交付；仅生成 ZIP/XML 不代表排版验证通过。Markdown 中的 pagebreak 标记映射为下一标题的段前分页，避免多余空白页。
